# Icon sources

- Font Awesome Free 6.7.2, Fonticons, Inc. — https://github.com/FortAwesome/Font-Awesome/tree/6.7.2 — CC BY 4.0 for SVG icons. See FONT-AWESOME-LICENSE.txt.
- Material Design Icons, Pictogrammers — https://github.com/Templarian/MaterialDesign — Apache License 2.0. Icons: atv, tent, room-service. See MATERIAL-DESIGN-LICENSE.txt.
- Camel by Delapouite, Game-icons.net — https://game-icons.net/1x1/delapouite/camel.html — CC BY 3.0, https://creativecommons.org/licenses/by/3.0/. Recolored with currentColor.
- Flag Icons, Lipis — https://github.com/lipis/flag-icons/tree/v7.3.2 — MIT. See FLAG-ICONS-LICENSE.txt.
- The excursions route combines the Font Awesome location icon with a project-authored dotted path.

The downloaded originals are retained alongside the inline sprite used by the page. Sprite paths are recolored to match the green and gold reference palette.
